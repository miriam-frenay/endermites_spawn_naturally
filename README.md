# Endermites Spawn Naturally

Spawns endermites naturally in the End Highlands when breaking endstone.

## Configuration

Change `spawn-chance` in `config.yml` to the desired spawn ratio per endstone blocks mined. The default value of `0.05` means 5 percent, for an average of 1 in every 20 blocks.
